## 二、主要工作与成果

### 1. 车间 ERP 系统——从 0 搭建并上线（本周核心工作）

为提升车间生产管理与进销存效率，独立开发了一套适配本厂业务的管理系统，并完成部署上线。

- **系统定位**：车间生产管理 + 轻量进销存，离线内网运行，不依赖外网与第三方服务。
- **覆盖模块**：生产日报 / 任务单报工、BOM 与 MRP 物料需求、原料与成品库存、报价单 / 销售订单、采购计划、品质检验、资金往来、报表中心。
- **岗位权限**：按 8 类角色（老板 / 管理 / 工程 / 采购 / 跟单 / 销售 / 车间 / 品检）做了数据权限隔离，各岗位只能查看与修改职责范围内的内容，避免误操作与越权。
- **部署上线**：将系统迁移至公司闲置电脑并注册为系统服务，实现**开机自启、崩溃自动重启**，车间通过内网电脑或平板即可访问，无需专人值守。
- **使用文档**：编写《车间工作台使用教学手册》，按岗位说明操作流程与权限边界，便于各岗位照着用。
- **使用方式（简单教程）**：
  - 网址：电脑 / 平板**连接公司内网**（同一 WiFi 或路由器）后，浏览器打开 `http://192.168.1.8:3100`（外网打不开）。
  - 管理员账号：`admin / wdf16888`（仅供管理 / 老板使用，首次登录请改密）。
  - 各岗位具体能看什么、能改什么、点哪几步，见《车间工作台使用教学手册》。
- **成本对比**：市面上功能相近的车间 ERP / 外包开发报价约 12000 元，本次为自主开发、零采购成本，相当于为公司省下这笔费用。

> 交付价值：车间生产数据从纸质 / 口头流转转为系统记录，报工、库存、订单状态可实时查询，管理侧有报表与看板支撑决策。
