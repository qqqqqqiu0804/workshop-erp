# 车间工作台（ERP）使用教学手册

> 适用：公司闲置电脑上运行的「车间工作台」系统（车间生产管理 + 进销存）。  
> 本文面向车间各岗位人员，先说明你在系统里能做什么、不能做什么，再讲怎么用那台闲置电脑。

---

## 〇、先记住三件事

1. 这台闲置电脑就是服务器：7×24 开机、连着车间 WiFi，系统作为 Windows 服务开机自启，崩了会自动重启。平时不要关机、不要断网、不要睡眠，否则全车间都访问不了。
2. 每个人用自己的账号登录：系统按「角色」控制你能看什么、能改什么。不要共用账号、不要泄露密码。
3. 所有操作都会留痕：改错了能查到是谁、什么时候改的，所以请按规范操作，别乱点。

- 访问地址：`http://192.168.1.8:3100`（建议固定 IP，见附录一；若地址变了以管理通知为准）
- 浏览器：Chrome / Edge 均可；平板用自带浏览器，建议「添加到主屏幕」当 App 用。
- 电脑/手机必须连接公司内网（同一 WiFi / 路由器）才能访问本工作台，外网打不开。
- 管理员账号：admin / wdf16888（首次登录请改密；此账号仅供管理/老板使用）。

# 第一部分：工作台使用流程（按岗位）

## 一、角色与权限总览

系统共 8 个角色，菜单可见性和可写权限都按角色区分。

通用页面（所有角色都能看）：工作台首页、生产日报、原料库存、成品库存、报表中心、物料需求(MRP)、资金往来（只读）。

各角色专属可见页面：

| 角色 | 车间对应岗位   | 除通用页外，还能看到                      |
| -- | -------- | ------------------------------- |
| 老板 | 负责人 / 老板 | 全部页面（含用户管理、员工、财务成本、老板驾驶舱、资金收付款） |
| 管理 | 系统管理员    | 全部页面（含用户管理、员工、财务成本、资金收付款）       |
| 工程 | 工艺 / 工程  | 商品（产品信息）、物料、工程BOM、BOM批量导入、智能导入  |
| 采购 | 采购       | 供应商、采购计划、采购订单、外发加工、智能导入         |
| 跟单 | 业务跟单     | 客户、销售订单、报价单、生产任务单、领料备料、智能导入     |
| 销售 | 销售       | 客户、销售订单、报价单、智能导入                |
| 车间 | 操作员 / 机长 | 生产任务单、领料备料、外发加工、品质              |
| 品检 | 品检员      | 品质、生产任务单、领料备料、外发加工              |

> 注：当前系统没有独立的「班组长」角色。班组长一般使用「车间」角色（与操作员同权限），额外负责现场监督与协调（详见第三节）。排产、派工等管理动作由「管理 / 跟单」在生产任务单里完成。

几个你可能看不懂的词（都是系统里的功能模块）：

- 智能导入：按模板批量录入资料（商品 / 物料 / 客户等），不会用就走单条新增。
- 老板驾驶舱：老板专属汇总看板（产值、应收应付、库存概况）。
- 资金收付款：收款、付款、采购发票三单匹配，只有老板 / 管理能操作。
- 工程BOM：每个成品的用料清单，是 MRP 自动算料的依据。

完整的「谁能改什么」权限总表见附录四（备查）。下面每个岗位只说你能做、不能做。

## 二、操作员（机台操作员 / 机长）——「车间」角色

你能看到的菜单：工作台首页、生产日报、原料库存、成品库存、生产任务单、领料备料、外发加工、品质、报表中心、物料需求、资金往来（只读）。

### 核心工作：报工（记录产量）

方式一：生产日报（没有任务单时，记录当天产量）

1. 进入「生产日报」→ 点「新增」。
2. 选机台（自动车 1–12 号 / 走心机 13–23 号）、工序、操作员工。
3. 填产量、良品数、不良数 → 保存。
4. 自己当天填错可「编辑 / 删除」该日报行。

方式二：任务单报工（有工单时，按工序流转）

1. 进入「生产任务单」→ 找到分配给自己的任务。
2. 按默认路线逐工序报工：自动车 → 走心机 → 品检 → 包装。
3. 在当前工序填产量、选**班次**（白班 08:00–20:30 / 夜班 20:00–08:00，系统按时间自动预选，交接时段 20:00–20:30 请手动确认）→ 提交；上一工序没完成不能跳过。
4. 全部工序完成 → 系统自动完工入库（成品进库存）。

> 任务单里的报工行不能直接改 / 删（系统会提示去任务单页处理），这是为了保留工序追溯链。要修改请联系管理在任务单里调整。

### 领料（去仓库拿料）

1. 进入「领料备料」→ 看跟单 / 管理为你这条任务生成的领料单。
2. 核对「应领量」与「实领量」→ 仓库发料后点「发料确认」。

### 外发（本厂做不了的工序）

- 进入「外发加工」→ 记录发外 / 回厂数量与状态。

### 你不能做的（会被拒绝）

- 不能改商品、物料、客户、供应商等任何档案。
- 不能改财务、不能做收付款。
- 资金往来页只能看，不能改。

## 三、班组长（带班主管）

- 系统里班组长通常使用「车间」角色（与操作员权限相同），由管理为你单独开一个账号。
- 你的额外职责（系统外 + 现场）：
  - 监督本班报工是否及时、准确；发现漏报 / 错报提醒操作员补正。
  - 关注「生产任务单」进度，发现某机台长时间无产出及时上报管理。
  - 协调领料、外发节奏，保证产线不断料。
- 说明：排产、派工、建任务单属于管理动作，由「管理 / 跟单」在生产任务单里完成；班组长主要做监督与现场协调，不在系统里额外开权限。

## 四、品检员 ——「品检」角色

你能看到的菜单：品质、生产任务单、领料备料、外发加工 + 通用页。

### 核心工作：检验记录

1. 进入「品质」→ 选择对应的生产任务单 / 工序。
2. 记录检验结果：合格 / 不合格、不良数量、不良原因。
3. 提交后，不合格品会进入返工 / 报废流程，相关工序需重做或处理。

### 你不能做的

- 不能改 BOM、商品、物料等档案。
- 不能改财务、不能做收付款。
- 生产任务单只能查看与关联检验，不能改派工数据。

## 五、跟单员（业务跟单）——「跟单」角色

你能看到的菜单：客户、销售订单、报价单、生产任务单、领料备料、智能导入 + 通用页。

### 日常工作

1. 报价：「报价单」→ 新建 → 选客户 → 加产品 / 数量 / 单价 → 发给客户 → 客户确认后点「转销售单」。
2. 接单排产：「销售订单」→ 查看 / 新建 → 对订单点「计划」→ 系统自动生成物料需求（MRP）和生产任务单草稿。
3. 领料：对生产任务单点「生成领料单」→ 交车间去领料。
4. 客户隔离：你只能看到归属自己（owner_role=跟单）的客户，其他跟单 / 销售的客户看不到，这是正常隔离，不是 bug。

### 你不能做的

- 不能改商品 / BOM（归工程）、不能改物料 / 供应商（归采购）。
- 不能改财务、不能做收付款。

## 六、销售 ——「销售」角色

你能看到的菜单：客户、销售订单、报价单、智能导入 + 通用页。

- 与跟单类似，偏前端接单与报价；新建客户、报价单、销售订单都在这里。
- 客户隔离同跟单：只看到自己名下的客户。
- 不能改生产、采购、财务、资金。

## 七、采购 ——「采购」角色

你能看到的菜单：供应商、采购计划、采购订单、外发加工、智能导入 + 通用页。

### 日常工作

1. 采购计划：MRP 跑出物料缺口 → 「采购计划」列表 → 指派供应商、转成采购订单。
2. 采购订单：「采购订单」→ 新建 PO → 供应商到货后入库（系统自动生成应付单）。
3. 外发加工：发外加工单的新建与跟进。

### 你不能做的

- 不能改商品 / BOM（归工程）。
- 不能改财务、不能做付款（付款归老板 / 管理在资金往来里做）。

## 八、工程 / 工艺 ——「工程」角色

你能看到的菜单：商品（产品信息）、物料、工程BOM、BOM批量导入、智能导入 + 通用页。

### 核心工作

1. 维护资料：商品（成品）资料、物料（原料）资料，可单条录入，也可用「智能导入」批量导入。
2. 建 BOM：每个成品的用料清单（含单台用量与损耗率）→ 这是 MRP 自动算料的依据，务必准确。
3. BOM 批量导入：多产品 BOM 一次性导入。

### 你不能做的

- 不能改销售、采购、财务、资金。
- 工程看全部客户（技术资料视角），但一般不碰客户业务数据。

## 九、管理员（系统管理）——「管理」角色

你能看到的菜单：全部页面（含用户管理、员工、财务成本、资金收付款、老板驾驶舱）。

### 核心职责

- 账号与权限：开账号、分配角色（用户管理页）。每个岗位一个账号、一个角色。
- 排产派工：在生产任务单里建任务、派给机台 / 班次。
- 库存盘点：成品库存 / 原料库存的盘点与调整。
- 资金收付款：在「资金往来」里做收款、付款、采购发票三单匹配。
- 会计记账：在「会计」页开账、录期初、录凭证、关账（详见第十一节）。
- 看板决策：报表中心、老板驾驶舱。
- 系统维护：服务启停、数据备份（见第二部分）。

> 管理员是超级权限，钱和账别一个人全管，重要改动先备份。

## 十、老板 / 负责人 ——「老板」角色

你能看到的菜单：全部页面 + 老板驾驶舱（汇总看板）。

- 老板驾驶舱一览：产值、应收未收、应付未付、净资金占用、库存概况——日常看这个就够了。
- 资金收付款也在「资金往来」里操作。
- 建议日常以「看板 + 报表」为主，具体录入交给各岗位，自己只做决策与资金动作。

## 十一、会计记账 —— 仅「老板 / 管理」角色

谁能用：**只有老板和管理**。其他岗位（操作员、品检、跟单、销售、采购、工程）看不到这个菜单，就算直接敲地址也会被挡回去——账目的事，车间不参与。

能干什么：科目表、会计期间（开账/关账/期末结转）、期初余额、记账凭证、试算平衡、账簿（总账/明细账/日记账/现金·银行·数量金额账）、报表（资产负债表/利润表），发票（销项/进项/费用登记+一键生成凭证）、发票风险扫描、资金一览、银企流水导入匹配，以及**工资**（档案/五险一金/专项附加扣除/月度工资单/发放入凭）和**固定资产**（卡片/类别/折旧自动计提/资产报表），还有**新报表**（现金流量表、多栏账、银企对账）和**旧账迁移**（把老的应收/应付/资金往来搬进会计账，搬完封存旧表）。

### 第一次使用，按顺序走这四步

1. **开账**：会计页右上角「＋ 开账」，填年份和月份（比如 2026 年 9 月），确定。这就是建一个月的账套。
2. **录期初**：切到「期初余额」页，把开业时的家底录进去——银行存款有多少、欠供应商多少、欠我们多少、库存值多少。
   - 一行的借方和贷方只能填一边。
   - 全部行的**借方合计必须等于贷方合计**，否则存不进去。
   - 只有第一个月需要录，后面每个月的期初从上个月自动带过来。
3. **录凭证**：切到「凭证」页「＋ 新增凭证」。选日期、类型（记/收/付/转），然后至少两行分录。
   - 每行选一个科目，填借方**或**贷方金额。
   - 涉及原材料、库存商品、在制品这些的，还要填**数量**（系统记数量金额）。
   - 底部会实时显示借贷差额，**差额必须是 0** 才能保存。
   - 存下来是「草稿」→ 点「审核」→ 点「记账」，这笔才算真正入账。
4. **关账**：这个月的账都记完、核对无误后，点右上角「关账」。关账前系统会检查试算平衡，不平不让关。
   - 关账后这个月就锁死了，不能再改。要改就点「反结账」，改完再关。

### 月末怎么出账和看报表（M1 新功能）

5. **期末结转**：关账**之前**，点右上角「期末结转」。系统会把本月所有损益类科目（收入、成本、费用）的余额，自动生成一张「转」字凭证，结转到「本年利润」。
   - 12 月（年末）会**额外再生成一张**凭证，把「本年利润」结转到「利润分配-未分配利润」。
   - 这两张都是**草稿**，要像普通凭证一样「审核 → 记账」才会真正生效。建议结转后先抽查金额，再记账。
6. **看账簿**：切到「账簿」页，有六类账可看——
   - **总账**：每个科目一个月的汇总（期初 / 本期借 / 本期贷 / 期末）；
   - **明细账**：某个科目逐笔的分录和每笔后的余额；
   - **日记账**：本月所有已记账凭证按时间顺序排；
   - **现金日记账 / 银行日记账**：分别对应「库存现金(1001)」「银行存款(1002)」的收支流水；
   - **数量金额账**：原材料、库存商品这些既记金额又记数量的科目，能看到数量和单价。
   - 账簿全是系统按凭证**实时算**出来的，改了凭证这里立刻跟着变，不用手动登记。
7. **看报表**：切到「报表」页——
   - **资产负债表**：看某一期的资产、负债、权益，系统会显示是否「平衡」（资产 = 负债 + 权益）；
   - **利润表**：看本期的收入、成本、费用、净利润；勾选「本年累计」能看到从年初到本月的累计数。
   - 报表也是实时算的，关账后数字就固定了。

### 怎么核对有没有记错

切到「试算平衡」页：期末借方合计和贷方合计相等、显示「平衡」，说明账是平的；显示「不平衡」，说明有凭证记错了，回去查凭证。

### 发票与银企流水（M2 新功能）

切到「发票」页，有六个子视图：

8. **销项发票**：抬头点「销项发票」→「＋ 新增」，填票号、开票日期、客户、税率（系统自动算税额和价税合计）→ 保存。登记完点「生成凭证」，系统自动出一张「转」字应收凭证（借 应收账款 贷 主营业务收入+销项税，带客户辅助核算）；凭证要像普通凭证一样「审核 → 记账」才生效。开错的发票点「作废」（已记账的要先反记账再作废）。
9. **进项发票**：同理，填供应商、资产科目（默认原材料 1403）→ 生成应付凭证（借 原材料+进项税 贷 应付账款，带供应商辅助）。
10. **费用单据**：填部门、费用科目（默认管理费用 5602）、付款科目（默认银行存款 1002）→ 生成费用凭证（借费用 贷银行，费用科目带部门辅助）。
11. **风险扫描**：点「扫描」，系统会查三类问题——重复票号、税率异常（高于 13% 或低于 3%）、逾期（超过信用期还没收/付）；结果列在「发票风险」子视图里，可反复扫。
12. **资金一览**：看销项/进项的张数和价税合计，以及按客户/供应商分组的情况，全是实时算的。
13. **银企流水**：把银行导出的流水（CSV 或 JSON）贴进文本框 → 点「导入」，系统自动和已记账凭证里的银行收支**匹配未达账**（流水支出匹配贷方 1002、流水收入匹配借方 1002，金额相等且 10 天内的自动对上）。没对上的留在「未达账」里，可以手工补匹配或取消。不做真实银行接口，纯导入+匹配。

> 发票功能只是「登记 + 一键出凭证草稿」，真正的入账动作（审核→记账）和普通凭证一样，由你把关，不会自动进账簿。

### 工资与固定资产（M3 新功能）

#### 工资（先配好基数，再按月出单）

14. **配工资档案**：切到「工资」页「工资档案」→「＋ 新增」，选员工、填基本工资、计件工价、加班单价、奖金、其他扣款。计件按「成品口径」算——系统取该员工报工里**完工数量 × 工价**，不会把前道工序重复算进去。
15. **配五险一金**：切到「五险一金」填公司/个人费率（全厂一条）。切到「专项附加扣除」给个别员工加子女教育、房贷、赡养老人等扣除项（没有就空着，不影响计算）。
16. **出工资单**：到 「工资单」→「生成工资单」，选月份 → 系统自动算每人：应发（基本+计件+加班+奖金−扣款）、代扣（个税+社保个人）、实发。个税按**累计预扣法**算（已经把前几个月累计进去了），结果标注「估算，以税务为准」。
17. **审核 → 发放**：工资单点「审核」，确认无误后点「发放」→ 系统自动出一张工资凭证（借 工资费用/社保(公司) 贷 应付职工薪酬/银行存款/应交个税/社保(个人)），凭证再走「审核→记账」生效。

#### 固定资产（卡片 + 自动折旧）

18. **建类别**：切到「资产」页「资产类别」→ 填名称、使用年限、残值率（默认 5%）、折旧方法（直线法 / 双倍余额递减法）。
19. **登卡片**：「资产卡片」→「＋ 新增」，填名称、类别、规格、数量、原值、启用日期、使用年限、残值率、折旧方法。机床一般选直线法。
20. **提折旧**：到月底点「计提折旧」，选月份 → 系统按方法算当月折旧、写折旧记录、自动出折旧凭证（借 管理费用-折旧 贷 累计折旧）。已提满或已处置的资产会自动跳过。
21. **看报表**：「资产报表」看原值/累计折旧/净值，按类别汇总，并和总账的固定资产(1601)/累计折旧(1602) 对账（显示是否一致）。
22. **处置**：资产报废/卖掉，点卡片「处置」→ 清算残值并出处置凭证。

### 旧账迁移与切换（M4 新功能，只用做一次）

切到「旧账迁移」页，按**顺序**走四步，别跳步：

23. **预检**（最重要，先做这个）：点「预检」。它会告诉你——老系统里应收有多少笔、应付有多少笔、金额多少、哪些能迁、哪些迁不了（比如缺客户或供应商、金额为 0）、要生成多少张凭证。**预检不会改动任何数据**，可以反复点。
24. **执行**：确认预检没问题后点「执行迁移」，选好期间。系统按老单据生成历史凭证（应收→借应收账款贷收入；应付→借原材料贷应付账款；收付款→银行与往来对冲），这些凭证**直接是已记账状态**（因为是已经发生过的老账，不用再审）。同一笔不会重复迁，所以中途断了可以再点一次接着补。
25. **校验**：点「校验对齐」，比对老系统的未收/未付余额和会计账里的应收/应付余额是否一致。一致才能进下一步；不一致说明还有单据没迁，回去跑预检看原因。
26. **封存**：确认无误后点「封存 / 解封」里的封存。封存后老的「资金往来 / 应收 / 应付」只能**看不能改**，以后一律走会计模块。封存是可逆的——确需回改，再点一次解封即可。

> ⚠️ 两条必须知道的口径：
> ① 老应收/应付表里**没有税额字段**，迁移过来的凭证不拆税（全额算收入/原材料）。要拆税得回到发票功能重新登记。
> ② 老单据转成凭证后，应收账款/应付账款的余额是凭证自动算出来的，**期初不用再录一遍**，否则会算两遍。

### 新增的三类报表（M4）

27. **现金流量表**：报表页下拉选「现金流量表」。用**间接法**——从净利润出发，加回折旧，再调整应收/应付/存货的变动，最后分成经营、投资、筹资三块，看「钱到底是怎么进出的」。最下面会显示是否与现金科目余额对得上；对不上会提示差多少（属于简化口径的正常提示，说明还有未纳入的调整项）。
28. **多栏账**：账簿页下拉选「多栏账」，再选科目（比如管理费用）。它会把这笔费用的**对方科目横向排开**（如分别付给银行存款、库存现金各多少），一眼看出钱花在哪儿。
29. **银企对账**：资金相关页看「余额调节表」——账面余额加上「银行已收企业未收」、减去「银行已付企业未付」，得到调整后余额，并列出未达账项（银行记了、账上还没记的笔数）。

### 几个容易踩的坑

- **借贷不等存不了**：这是故意的，不是系统坏了。一笔业务必须有借有贷、金额相等。
- **数量金额科目漏填数量**：原材料、库存商品、在制品、生产成本下的直接材料，都要填数量，否则保存时会被拦下。
- **科目不够用**：科目表里已有 64 个常用科目（含在制品、委外加工费、模具这些本厂特有的）。确实缺的，在「科目表」页「＋ 新增科目」自己加。
- **关账后改不了**：先反结账，改完记得再关账。

> 会计账和原来的「财务 / 资金往来」是两套，暂时并行。资金往来照常用，会计账是给正式做账和代账用的。

# 第二部分：如何使用这台闲置电脑

## 1. 开机与日常唤醒

| 场景      | 怎么做                                 |
| ------- | ----------------------------------- |
| 正常上班    | 电脑应已开机并自动运行系统。打开浏览器输入地址即可登录，无需任何操作。 |
| 早上发现没开机 | 直接按电源键开机 → 约 30 秒后系统自启完成 → 浏览器访问地址。 |
| 换班 / 午休 | 电脑保持开机，不要关机、不要合盖睡眠。                 |

> 系统已设为开机自启 + 崩溃自愈，只要电脑通电联网，基本不用管它。

## 2. 基础设置（仅「管理 / 老板」操作）

- 固定 IP（强烈建议）：在路由器把本机 MAC 绑定到固定内网 IP（如 192.168.1.8），防止 WiFi 一换 IP 平板就连不上。详见附录一。
- 防火墙：安装时已放行 3100 端口入站，一般无需再动。
- 保持干净：不装无关软件、不插不明 U 盘、不拿它上外网下载东西，避免中毒或卡顿影响车间使用。

## 3. 日常操作（任何人都可能用到）

1. 在车间电脑或平板上打开浏览器，地址栏输入 `http://192.168.1.8:3100`。
2. 输入自己的账号和密码 → 登录。
3. 左侧菜单只显示你这个角色有权限的页面，按菜单进入操作即可。
4. 用完点右上角「退出」再离开（尤其在公用电脑上）。

> 卡顿 / 白屏：先刷新页面（F5 / 下拉刷新）；仍不行联系管理，不要反复乱点。

## 4. 故障应急（仅「管理 / 老板」）

| 现象           | 处理                                                                      |
| ------------ | ----------------------------------------------------------------------- |
| 浏览器打不开 / 连不上 | 先确认这台电脑已开机、WiFi 已连；再让管理用管理员命令行执行 `sc query WorkshopERP` 看服务是否在 RUNNING。 |
| 服务没起来        | 管理员命令行：`nssm restart WorkshopERP`（或 `sc start WorkshopERP`）。            |
| 端口被占         | 检查是否有别的程序占了 3100；释放后重启服务。                                               |
| 完全卡死         | 直接重启这台电脑，服务会随开机自动拉起。                                                    |
| 数据异常         | 数据有问题联系管理/开发，从备份恢复，不要自己动库文件。                                            |

## 5. 停机维护（仅「管理 / 老板」）

- 维护前先通知车间各岗位暂停操作。
- 管理员命令行：`nssm stop WorkshopERP` 停服务 → 维护 → `nssm start WorkshopERP` 恢复。
- 数据文件 `data/workshop.db` 不要手动删除或修改，否则数据会丢。

# 附录一：固定 IP（防止连不上）

> WiFi 一切换 IP 就可能变，平板会直接连不上，务必固定。

- 首选：路由器 DHCP 保留——登录路由器，把本机 MAC 绑定到固定内网 IP（如 192.168.1.8）。换网线 / 重连也不变，且不与其他设备冲突。
- 备选：网卡静态 IP——Windows：控制面板 → 网络连接 → 对应网卡 → 属性 → IPv4 → 手动填（IP / 子网 255.255.255.0 / 网关 192.168.1.1 / DNS 114.114.114.114）。

固定后，访问地址固定为 `http://<固定IP>:3100`，平板和车间电脑不用再改。

# 附录二：常见报错与处理

| 提示 / 现象      | 原因                  | 处理                    |
| ------------ | ------------------- | --------------------- |
| 「无权限：需要角色 …」 | 当前角色不能改该数据          | 找对应角色的人操作，或让管理调整权限    |

# 附录三：安全与规范

- 密码不共享、不写在纸上；离开公用电脑点「退出」。
- 连续输错密码会被临时锁定（防暴力破解）。
- 所有增删改都会记入审计日志，操作前确认数据正确。
- 数据定期备份（`data/workshop.db`），由管理执行；不要手动改库文件。
- 这台电脑只跑工作台，基础设置里的"保持干净"要求见第二部分第 2 节。
