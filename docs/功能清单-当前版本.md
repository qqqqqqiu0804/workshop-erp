# workshop-app 功能清单（当前版本）

> 生成日期：2026-08-29 ｜ 基准 commit：`74d71ee`（含 madge 依赖图谱）
> 用途：作为「当前版本真实功能」的基准，与 GitHub 仓库内各文档（`README.md` / `业务逻辑完整手册.md` / `前端审查与优化方案.md` / `ERP待补充清单.md` 等）逐项比对校验。
> 代码事实来源：`server.js` 挂载的 28 个 API 模块 + `public/js/pages/` 的 24 个前端页面 + 阶段6 安全收尾。

## 一、技术底座与运行

- **后端**：Node.js 22 + Express 4 + 内置 `node:sqlite`（`DatabaseSync`，WAL、`foreign_keys=ON`、`busy_timeout=5000`）。**零原生依赖、零编译**，适配车间离线部署。
- **前端**：原生 HTML/CSS/JS 单页应用（SPA），无框架、无构建、无 CDN，离线可用。
- **脚本合并**：24 个页面脚本物理拼接为 `public/js/pages/pages.bundle.js`（`build-pages.js` + `npm run build:pages`，含顶层声明重名自校验）；首页仅 4 个 `<script>`（common / bundle / icons / app），均 `defer`；静态资源 `Cache-Control: max-age=3600` + ETag。
- **启动**：`npm install` → `npm start`（默认 3000；本机验证用 `PORT=3100`）。`npm run reset --yes` 清空到主数据基线；`npm run seed` 为 no-op。
- **测试**：`npm test`（node --test 零依赖，打已运行服务）**180/180 全绿**（含会计 M0 136 + M1 6 + M2 8 + M3 12 + M4 11 + 驾驶舱 7；env 驱动用例可经 `TEST_BASE`/`BASE` 指向非 3100 端口服务）。
- **可选 HTTPS**：设 `SSL_KEY` / `SSL_CERT` 环境变量即用自签证书（生成见 `node gencert.js`）。

## 四、生产

| 模块 | 页面/路由 | 功能要点 |
|---|---|---|
| 生产日报 | `/api/production`（**无独立前端页**） | 手工日报接口（task_id 为空，产量报表数据源之一）；PUT/DELETE 仅允许编辑/删除手工日报行（任务单报工行不可，护 ISO 追溯） |
| 生产任务单（⭐ P1） | 生产任务单 `/api/production-tasks` | 建单（默认工序路线 自动车→走心机→品检→包装，可改）；逐道工序报工（写 `production_log` 带 task_id/operation_id，多次）；完工入库（取末工序累计量回写 `fg_stock_in` 带 task_id，置已完成）；状态机 待开工→进行中→已完成；**ISO 工序级追溯链** |
| 工程 BOM（P2） | 工程 BOM `/api/boms` | 单版本（每成品一条）；`bom_items`（qty_per 单耗 / loss_rate 默认 3%）；详情带物料实时库存 |
| BOM 导入（P7） | BOM 导入 `/api/bom-import` | Excel `preview`（解析+校验不写库）/ `commit`（按成品聚合写 BOM，已有 BOM 整单跳过）；损耗率默认 3% |
| MRP（P2） | MRP 运算 `/api/mrp` | 净需求 = `qty × qty_per × (1+loss_rate)`，**向上取整**；缺口 = `max(0, 需求−库存)`；纯查询不写库 |

**产量聚合口径（2026-08-25 修正，文档须与此一致）**：成品产量 = 任务单末工序(max seq)报工量 + 日报(task_id 空)行，**不做工序相加**；另提供「工序加工量」(全部报工原始量) 分开展示。

- **真 RBAC 登录（P11）**：`users`（scrypt 密码 + 随机 salt）/ `sessions`（sha256 token，httpOnly+sameSite=lax+7天 Cookie）；`server.js` 全局 `requireAuth`（跳过 `/api/health`、`/api/auth/*`）；`requireRole(...)` 角色权限；`visibleCustomerIds(role)` 客户隔离（管理/工程/采购/老板看全部，跟单/销售仅见 `owner_role=自身`）。默认种子账号 `admin/Wk9mP2@qL5nR#7`（角色 老板），启动 `console.warn` 提醒改密。
