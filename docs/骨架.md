## 3 各模块职责

### M0 会计核心（详）
- **accounts**：科目表。5 大类（资产/负债/权益/收入/费用），支持父子（明细科目可记账、非明细为类别节点）。字段含辅助核算类型、是否数量金额核算、计量单位、科目借贷本性。提供《小企业会计准则》一级科目模板 CSV 导入 + 自定义明细。
- **periods**：会计期间（年+月）。状态 `open` / `closed`；关账后拒收/拒改该期凭证，需反结账才能再开。
- **vouchers**：凭证头（凭证号/日期/期间/类型 记·收·付·转/摘要/制单·审核人/状态 草稿·已审·已记账）+ 分录行。后端强校验**借贷必相等**，不等拒存。
- **opening**：首期期初余额录入（各科目借/贷期初；存货科目带数量）。之后各期期初 = 上期期末（实时算，不冗余）。
- **balances**：试算平衡（全部科目借合计==贷合计）、科目余额表（期初+本期+期末，实时 SQL）。

### M1 账簿与报表（✅ 已实现）
- **ledgers**：从已记账凭证**实时 SQL** 生成六类账，不冗余落库：
  - `GET /ledgers/general?period_id=` 总账（期初/本期借/本期贷/期末；余额为零科目从结果省略）；
  - `GET /ledgers/detail?period_id=&code=` 明细账（该科目逐笔分录 + 每笔后余额，按 `balance_dir` 累加）；
  - `GET /ledgers/journal?period_id=` 日记账（已记账凭证按时间序）；
  - `GET /ledgers/cash?period_id=` 现金日记账（库存现金 1001）；
  - `GET /ledgers/bank?period_id=` 银行日记账（银行存款 1002）；
  - `GET /ledgers/qty?period_id=` 数量金额账（enable_qty 科目，含借/贷数量与单价）。
- **reports**：
  - `GET /reports/balance-sheet?period_id=` 资产负债表（资产/负债/权益分类，返回 `balanced` / `total_assets` / `total_liabilities_equity`）；
  - `GET /reports/income-statement?period_id=&ytd=1` 利润表（本月 / 本年累计，按 code 取数）。
- **carryforward**：`POST /periods/:id/carryforward` 期末结转——损益类科目余额→「本年利润(3103)」生成转字草稿；`month=12` 再生成「本年利润→利润分配-未分配利润(3104)」第二张凭证（金额=现有本年利润余额+本月净利润），返回 `is_year_end` / `vouchers`。关账前执行，需审核+记账生效（不自动）。

### M2 发票与资金（✅ 已实现）
- **invoices**（销项/进项/费用 + 风险 + 一览）：
  - 销项：`GET/POST /invoices/sales`；`POST /invoices/sales/:id/voucher` 生成应收凭证（借 1122 贷 5001+2221，带 aux_customer_id）；`POST /invoices/sales/:id/void` 作废（已记账凭证需先反记账）；税率 >1 视为百分数，自动算 tax_amount/total。
  - 进项：`GET/POST /invoices/purchase`（supplier_id + asset_account 默认 1403）；`POST /invoices/purchase/:id/voucher` 生成应付凭证（借 1403+2221 贷 2202，带 aux_supplier_id）；`POST /invoices/purchase/:id/void`。
  - 费用：`GET/POST /invoices/expense`（dept_id + fee_account 默认 5602 + payment_account 默认 1002）；`POST /invoices/expense/:id/voucher` 生成费用凭证（借费用 贷银行，费用科目按 accounts.aux 含 dept 时带 aux_dept_id）。
  - 风险：`POST /invoices/risk/scan` 覆盖式全量扫描（重复票号 / 税率异常 >13% 或 <3% / 逾期超信用期），写 `invoice_risk_logs`；`GET /invoices/risk`。
  - 一览：`GET /invoices/summary` 销项/进项汇总（张数/价税合计）+ 按客户/供应商分组，实时 SQL。
  - 凭证生成：与 M1 结转一致，`createInvoiceVoucher` 生成「转」字草稿（BEGIN/COMMIT 内、借贷双重校验），不自动审核记账；关账期间 `periodOpen` 前置拒生成。
- **bank**（银企流水导入 + 自动匹配，不做真实银行 API）：
  - `POST /bank/import`（body.items：trans_date/summary/direction 借|贷/amount）→ 写 `bank_statements`（`matched` 默认 0）+ `autoMatch`：流水「借」=银行支出匹配凭证明细 `credit` 含 1002；「贷」=银行收入匹配 `debit` 含 1002；条件 `金额 ROUND 相等 AND |julianday(凭证明细日期)-julianday(trans_date)|<=10`，已匹配凭证不二次匹配；返回 imported/matched/unmatched。
  - `GET /bank/statements?matched=0|1`、`GET /bank/unmatched`、`POST /bank/:id/match`（手工补匹配，需金额相等且 10 日内）、`POST /bank/:id/unmatch`。

### M3 工资与固定资产（✅ 已实现）
- **payroll**（工资：档案/五险一金/专项附加扣除/月度工资单/发放/统计）：
  - `GET/POST /payroll/profiles` 工资档案（employee_id 唯一、base_salary、piece_rate、overtime_rate、bonus、other_deductions、salary_subject 默认 400102、pay_account 默认 1002）。
  - `GET/POST /payroll/social` 五险一金配置（company_rate/personal_rate、subject 默认 5602，全厂一条）。
  - `GET/POST /payroll/tax-deductions` + `DELETE /payroll/tax-deductions/:id` 员工专项附加扣除（子女教育/房贷/赡养老人等，月额度）。
  - `POST /payroll/sheets/generate` 生成某期工资单：基本 + 计件（成品口径：tasks.finished_qty × 工价，避免前道重复计件）+ 加班 + 奖金 − 扣款；**个税按累计预扣法精确估算**（累计收入 − 累计免税 − 累计专项扣除 − 累计专项附加扣除 − 累计减除费用 5000×月数 → 对照预扣率表得累计税额 − 已预缴），标注「估算」；返回应发/代扣(个税+社保个人)/实发。
  - `GET /payroll/sheets?period_id=` 工资单列表；`POST /payroll/sheets/:id/approve` 审核；`POST /payroll/sheets/:id/pay` 发放并自动生成凭证（借 工资费用/社保(公司) 贷 应付职工薪酬/银行存款/应交个税/其他应付款-社保(个人)，借贷双重校验、BEGIN/COMMIT）。
  - `GET /payroll/summary?period_id=` 工资汇总（应发/代扣/实发 + 按员工明细）。
  - 计件口径：工价挂在「工序」(products 工序工价) 而非产品整体，产量取 `production_log` 原始报工量；与 M1/M2 一致，避免驾驶舱「达成率」同款口径坑。
- **assets**（固定资产：类别/卡片/折旧/处置/报表）：
  - `GET/POST /assets/categories` 资产类别（name、default_life_years、default_salvage_rate 默认 0.05、default_method 直线|双倍余额）。
  - `GET/POST /assets` 资产卡片（code、name、category_id、spec、qty、unit、origin_value、start_date、life_years、salvage_rate、method、accumulated_depreciation 默认 0、status 在用|闲置|处置）；`PUT /assets/:id` 变更；`POST /assets/:id/dispose` 处置（清算残值、生成处置凭证）。
  - `POST /assets/depreciation/run` 某期折旧计提：按 method 算当月折旧（直线：原值×(1−残值率)/年限/12；双倍余额：(原值−累计折旧)×2/年限/12），写 `depreciation_records` 并自动生成折旧凭证（借 费用科目 贷 累计折旧 1602，借贷校验）；已提满或已处置跳过。`GET /assets/depreciation?period_id=` 折旧明细。
  - `GET /assets/summary` 资产报表：原值/累计折旧/净值 + 按类别汇总 + 与总账 1601/1602 核对标志（reconciled）。
  - 关账期间 `periodOpen` 前置拒生成凭证（工资发放、折旧计提均受控）。

### M4 报表补全与旧账迁移（✅ 已实现）
- **migration**（旧 `finance_ledger / ar_invoices / ar_receipts / ap_invoices / ap_payments` → `accounting.db`）：
  - **跨库铁律**：只读旧库取数 → JS 内映射 → 写入新库，**禁止跨库 JOIN / 跨库事务**。
  - `POST /migration/preview` 预检：**只统计不写库**（各旧表行数/金额、可迁数、不可迁原因、预计凭证数与类型分布、借贷不等计数、口径警告）。闲置机真实旧账必须先跑预检再决定执行。
  - `POST /migration/run` 执行：**幂等**（`migration_log(source_table, source_id, target_type)` 唯一去重，可重复执行补漏）；迁移凭证 `status='posted'` 直接记账（历史事实不可逆）；期初**只记资金(1002)净额 + 3104 平衡项**——1122/2202 由迁移凭证自然产生，再记即双重计算。
  - 映射：`ar_invoices`→借1122(客户辅助) 贷5001；`ar_receipts`→借1002 贷1122；`ap_invoices`→借1403 贷2202(供应商辅助)；`ap_payments`→借2202 贷1002。旧表无税额字段，**不拆税**（全额入收入/原材料）。
  - `GET /migration/verify` 校验：旧表未结应收/应付 vs 新账 1122/2202 余额，返回 `diff` 与 `aligned`。
  - `POST /migration/seal` / `unseal`：软封存（`migration_state.sealed`），`guardSealed` 中间件挂在 `ar.js / ap.js / finance.js` 拒绝写（POST/PUT/PATCH/DELETE），读不受影响；可解封回滚，旧表永不删除。
- **reports**：`GET /reports/cash-flow?period_id=` 现金流量表（**间接法**：净利润 + 折旧/摊销 + 经营性往来与存货变动 → 经营/投资/筹资；返回 `residual` 残差与 `reconciled` 勾稽标志）。
- **ledgers**：`GET /ledgers/multi-column?period_id=&account_code=` 多栏账（按**对方科目**横向分栏，复合分录按对方科目金额比例分摊）。
- **bank**：`GET /bank/reconcile?period_id=&account=1002` 银企对账/余额调节表（账面余额 + 银行已收企业未收 − 银行已付企业未付 = 调整后余额，附未达账项；流水表无「对账单余额」列，暂不与银行对账单最终余额勾稽）。

## 5 关键数据结构（M0 建表概要）

```sql
-- 科目表（code 为业务主键，层级用 parent_code 自引用）
CREATE TABLE accounts (
  code         TEXT PRIMARY KEY,            -- 如 1001 / 1403 / 5001
  name         TEXT NOT NULL,
  category     TEXT NOT NULL,              -- asset/liability/equity/income/expense
  parent_code  TEXT,                       -- 非明细科目的父级（类别节点）
  is_detail    INTEGER NOT NULL DEFAULT 1, -- 1=可记账明细科目
  aux          TEXT DEFAULT '',           -- 辅助核算：customer,supplier,dept（逗号分隔）
  enable_qty   INTEGER NOT NULL DEFAULT 0,-- 1=数量金额核算（仅存货类4科目）
  unit         TEXT DEFAULT '',           -- 计量单位（enable_qty=1 时）
  balance_dir  TEXT NOT NULL DEFAULT '借',-- 科目本性：借/贷
  status       TEXT NOT NULL DEFAULT 'active',
  FOREIGN KEY (parent_code) REFERENCES accounts(code)
);

-- 会计期间
CREATE TABLE accounting_periods (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  year       INTEGER NOT NULL,
  month      INTEGER NOT NULL,
  start_date TEXT,
  end_date   TEXT,
  status     TEXT NOT NULL DEFAULT 'open', -- open/closed
  closed_at  TEXT,
  closed_by  INTEGER,
  UNIQUE (year, month)
);

-- 凭证头
CREATE TABLE vouchers (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  voucher_no TEXT NOT NULL,               -- 如 记-0001
  date       TEXT NOT NULL,
  period_id  INTEGER NOT NULL REFERENCES accounting_periods(id),
  type       TEXT NOT NULL DEFAULT '记',  -- 记/收/付/转
  summary    TEXT,
  creator_id INTEGER,
  auditor_id INTEGER,
  status     TEXT NOT NULL DEFAULT 'draft', -- draft/audited/posted
  created_at TEXT NOT NULL DEFAULT (datetime('now','localtime')),
  UNIQUE (period_id, voucher_no)
);

-- 凭证明细分录（借贷同凭证必相等，由 API + 入库前双重校验）
CREATE TABLE voucher_entries (
  id               INTEGER PRIMARY KEY AUTOINCREMENT,
  voucher_id       INTEGER NOT NULL REFERENCES vouchers(id) ON DELETE CASCADE,
  seq              INTEGER NOT NULL,
  account_code     TEXT NOT NULL REFERENCES accounts(code),
  summary          TEXT,
  debit            NUMERIC NOT NULL DEFAULT 0,  -- 借方金额
  credit           NUMERIC NOT NULL DEFAULT 0,  -- 贷方金额
  qty              NUMERIC DEFAULT 0,           -- 数量（enable_qty 科目必填）
  price            NUMERIC DEFAULT 0,           -- 单价
  aux_customer_id  INTEGER,                     -- 辅助核算：客户
  aux_supplier_id  INTEGER,                     -- 辅助核算：供应商
  aux_dept_id      INTEGER,                     -- 辅助核算：部门
  CHECK (debit >= 0 AND credit >= 0 AND (debit = 0 OR credit = 0)) -- 单行只借或只贷
);

-- 期初余额（仅首期/手动录入；之后各期期初由期末实时推导，不冗余）
CREATE TABLE opening_balances (
  period_id   INTEGER NOT NULL REFERENCES accounting_periods(id),
  account_code TEXT NOT NULL REFERENCES accounts(code),
  debit       NUMERIC NOT NULL DEFAULT 0,
  credit      NUMERIC NOT NULL DEFAULT 0,
  qty         NUMERIC DEFAULT 0,
  PRIMARY KEY (period_id, account_code)
);
```

**余额实时算法**（与 workshop.db「派生数据实时算」原则一致，不冗余存 account_balances）：
- 期初 = `opening_balances`（首期）+ 之前所有已记账凭证的（借−贷）累计；存货另加 `qty` 累计。
- 本期发生 = 本期间 `status='posted'` 凭证的分录汇总。
- 期末 = 期初 + 本期发生。
- 试算平衡 = Σ(所有科目期末借方) == Σ(所有科目期末贷方)。

## 6 主链路时序（M0 最小闭环）

```
① 导入/建科目  →  accounts (小企业准则模板 + 工厂明细)
        ↓
② 开账          →  periods (建首期，触发期初录入)
        ↓
③ 录期初        →  opening_balances (各科目借/贷期初；存货带数量)
        ↓
④ 录凭证(草稿)  →  vouchers + voucher_entries (API 校验 借==贷，否则拒)
        ↓
⑤ 审核          →  vouchers.status: draft → audited
        ↓
⑥ 记账          →  vouchers.status: audited → posted (+ 审计日志)
        ↓
⑦ 试算平衡      →  /trial-balance 实时 SQL（借合计==贷合计）
        ↓
⑧ 关账          →  periods.close（前置校验试算平衡通过；关后改凭证明拒）
```

> 第 ④ 步借贷不等 / 第 ⑧ 步关账后改凭证 / 非老板管理角色写 → 均按 Stage 5 安全审查逐条卡住。
